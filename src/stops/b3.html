Bridge to stop 4

Names, references and linked structures

Big idea

In Python a variable is a name tag tied to an object, not a box holding it. Trees are objects pointing at objects. Every BST operation in stop 4 relies on one habit: a function that might replace a subtree returns the new subtree, and the caller re-attaches it.

Names are tags, not boxes

Kind of statementExampleEffect on other names for the same object
Mutate the objectb.append(3), b[0] = 9, node.left = xVisible through every name
Rebind the nameb = [0], b = b + [4], node = Node(5)Only this name moves; others are untouched

Studies of students learning Python keep finding that a shaky picture of references causes later confusion, so it is worth getting this exactly right now.

Passing to a function works the same way

A parameter is just a new name for the caller's object. Mutating it is visible to the caller; rebinding it is not.

When node is None there is no object to mutate, so the new node can only reach the tree if the function returns it and the caller writes parent.left = insert(parent.left, value).

Linked lists: the training ground for trees

A linked-list node has one pointer (next); a tree node has two (left, right). Every pattern you need for trees appears first on lists.

QuestionOn a listOn a binary tree (stop 4)
How many nodes?0 if h is None else 1 + length(h.next)0 if n is None else 1 + size(n.left) + size(n.right)
Find a valuewalk next until found: O(n)go left or right each step: O(h)
Delete a nodereturn head.next to skip itreturn a child (or a successor) to replace it
Exam traps

b = a does not copy a list; use a[:] or list(a). In reverse, overwriting cur.next before saving it loses the rest of the list. In any recursive structure, calling delete(head.next, x) without assigning the result back silently changes nothing.

Remember
  • Mutating an object is seen through every name; rebinding a name is not.
  • A function that may replace the head or a subtree must return it, and the caller re-attaches it.
  • Lists are trees with one child: recursion on them has the same shape.
