Pairs, sets and grids: the language of graphs

Big idea

A graph is a set of things V and a set of pairs E. Stop 7 writes everything in that notation and stores it in Python lists of lists, dictionaries and matrices. Get comfortable with pairs, set notation and nested lists first, including the one Python trap that silently corrupts an adjacency matrix.

Relations become graphs

Any rule saying which things are connected is a graph. Whether the rule is symmetric decides the kind: "is a friend of" works both ways, so it is undirected; "follows" on social media need not, so it is directed; "must happen before" never loops back, so it is a directed graph without cycles.

How many edges can there be?

Using bridge 5.5's counting: with n vertices there are C(n, 2) = n(n − 1)/2 unordered pairs, so at most that many undirected edges (no self-loops, no repeats). Ordered pairs give at most n(n − 1) directed edges. Either way E = O(V²), which also means log E = O(log V).

Remember
  • (u, v) is ordered (directed edge); {u, v} is unordered (undirected edge).
  • At most n(n − 1)/2 undirected or n(n − 1) directed edges: E = O(V²).
  • Build matrices with [[0] * C for _ in range(R)], never [[0] * C] * R.
  • Grids are graphs: 4 neighbours inside, 3 on an edge, 2 in a corner.
