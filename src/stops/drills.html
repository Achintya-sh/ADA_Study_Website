Writing an algorithm from memory is where marks go missing: an index off by one, a < that should be <=, a forgotten copy. Each drill hides the lines that matter. Type them from memory. Enter checks a drill and Tab jumps to the next blank. Spaces and quote style don't matter; capital letters do, just like real code.

Your first check on each drill is what's scored. Drills you get wrong are saved to My mistakes.
