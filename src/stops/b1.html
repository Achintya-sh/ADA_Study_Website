Growth, limits and induction

Big idea

Stop 2 compares functions as n grows huge, and proves recurrences with induction. Two tools make that painless: look at the ratio f(n)/g(n) as n grows, and learn the four-line shape of a proof by induction.

Who wins eventually? The ratio test

To compare two running times, divide one by the other and see where the ratio heads as n gets large:

f(n) / g(n) as n growsMeaningExample
→ 0f grows strictly slower: f = O(g) but not Θ(g)100n / n² = 100/n → 0
→ a constant c > 0Same growth: f = Θ(g)(3n² + 5n) / n² → 3
→ ∞f grows strictly faster: f = Ω(g) but not Θ(g)2ⁿ / n¹⁰⁰ → ∞, eventually

This is a shortcut, not the definition. Stop 2 gives the formal version with constants c and n₀; the ratio test tells you quickly which answer to aim for.

Exam trap

Log bases don't matter; exponential bases do. log₂ n = 3.32 · log₁₀ n, a constant factor, so both are Θ(log n). But 4ⁿ / 2ⁿ = 2ⁿ → ∞, so 4ⁿ is not O(2ⁿ). Similarly 2ⁿ⁺¹ = 2 · 2ⁿ is Θ(2ⁿ), while 2²ⁿ = 4ⁿ is not.

Proof by induction in four lines

Induction proves a statement P(n) for every n by knocking over dominoes: show the first one falls, and show that any falling domino knocks over the next.

  1. Claim. State P(n) exactly.
  2. Base. Check P(1) (or P(0)) directly.
  3. Step. Assume P(k) is true for some k (the inductive hypothesis) and use it to show P(k + 1).
  4. Conclude. P(n) holds for all n ≥ the base.
Worked example

Claim: 1 + 2 + … + n = n(n + 1)/2.
Base: n = 1 gives 1 = 1·2/2. ✓
Step: assume 1 + … + k = k(k + 1)/2. Then 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2, which is the formula for k + 1. ✓
Conclude: true for every n ≥ 1.

The same proof shows the recurrence T(1) = 1, T(n) = T(n − 1) + n solves to n(n + 1)/2: Quick Sort's worst case.

Stop 2's substitution method is exactly this: guess the answer to a recurrence, then prove the guess by induction. If you can do the sum above, you can do that.

Why analyses pretend n is a power of 2

Recurrences like T(n) = 2T(n/2) + n only make sense when n/2 is a whole number. Analyses assume n = 2ᵏ so every split is exact; for other n the true cost sits between the costs at the neighbouring powers of 2, which differ by at most a constant factor. The Θ answer doesn't change, so the simplification is safe.

Remember
  • Ratio → 0: slower. → constant: Θ. → ∞: faster.
  • logs < powers < exponentials < factorials. Log bases are constants; exponential bases are not.
  • Induction: claim, base, step (assume k, prove k + 1), conclude.
