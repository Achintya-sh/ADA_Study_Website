Bridge to the exam line

Choosing the technique

Big idea

Exam questions rarely say "use DP". They describe a problem and leave the choice to you. This stop connects every technique in the course: what each one assumes, what it costs, and the words in a question that point to it.

One problem, four techniques

"In how many ways can you climb n stairs taking 1 or 2 steps at a time?"

TechniqueWhat it doesCost
Backtracking (stop 6)lists every way, one by onegrows like 1.6ⁿ: at n = 40 that is 165,580,141 ways
Plain recursioncounts without listing, but repeats subproblemsalso exponential
Memoized recursion (stop 9)remembers each countO(n) time, O(n) space
Bottom-up DP (stop 9)fills the table from small to largeO(n) time, O(1) space with two variables

The question asked for a count, not a list, so listing every way is wasted effort. Reading what is actually asked is the first decision.

Questions to ask, in order

  1. Must every valid arrangement be listed? Backtracking, with pruning (stop 6). Check the size with bridge 5.5.
  2. Is it a minimum, maximum or count over many choices, and do smaller versions repeat? Dynamic programming (stops 9–10). Consider greedy only if you can prove it (bridge 8.5).
  3. Is it a graph or a grid? Fewest steps with equal-cost moves: BFS. Reachability, connected groups, cycles: DFS (stop 8).
  4. Do you repeatedly need the current best item? A heap (stop 5).
  5. Must data stay sorted while it changes, with order queries? A BST (stop 4).
  6. Does it split into independent halves? Divide and conquer; write and solve the recurrence (stops 2–3).
  7. Is it "have I seen this before?" A set or dictionary: O(1) average lookups (stop 0).

Then check the input size against stop 1's table: n ≤ ~11 allows n!, n ≤ ~25 allows 2ⁿ, n up to about 10⁶ needs O(n log n) or better.

Exam trap

Two answers can both be "correct" and still score differently. DFS finds a path; only BFS guarantees the shortest one in an unweighted graph. Greedy gives an answer; only a proof (or DP) makes it the best one. Say which guarantee your choice gives.

Remember
  • Read what is asked: list, count, best, or yes/no. Counting is not listing.
  • Overlapping choices + best/count → DP. Equal-cost fewest steps → BFS. All arrangements → backtracking.
  • Check n against the time budget before writing anything.
