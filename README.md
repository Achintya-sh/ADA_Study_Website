# ADA study notebook

A single-file study site for the Analysis and Design of Algorithms course, built from tested sources.

- `docs/context.md`  what the project is and the rules it follows
- `docs/handover.md` how to build, test and change it; open items
- `docs/roadmap.md`  the plan to turn it into a hosted site with synced progress

Quick start: `python build.py && python tests/tests.py && python tests/t2.py && python tests/t3.py && python tests/t4.py && python tests/t5.py`
